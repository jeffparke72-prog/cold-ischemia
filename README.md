# Cold Ischemia Foundation — Website

Static site files for coldischemia.foundation.

## Push this to GitHub

1. Create a new empty repository on GitHub (no README/license, so it stays empty).
2. In this folder, run:

```
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPO.git
git branch -M main
git push -u origin main
```

## Hosting with GitHub Pages

- Go to the repo's Settings → Pages
- Set Source to "Deploy from a branch", branch `main`, folder `/ (root)`
- Your site will be live at `https://YOUR-USERNAME.github.io/YOUR-REPO/`
- To use coldischemia.foundation as a custom domain, add a `CNAME` file containing just the domain, and point your DNS to GitHub Pages.
